# Информационная система по ремонту компьютерной техники «ТехСервис»

Веб-приложение для автоматизации сервисного центра по ремонту компьютерной техники.

## Команда разработчиков
- **Шулбаев К.Е.** — Проектирование и разработка базы данных PostgreSQL, заполнение данными, тестирование ПО (`schema.sql`).
- **Пасечник Б.Е.** — Разработка модуля регистрации и авторизации, модуля обработки заявок и модуля уведомлений (`app.py`, `config.py`).
- **Мурадов М.Р.** — Прототипирование в Figma, разработка пользовательского интерфейса и клиентской логики (`templates/`, `static/`).

## Стек технологий
- **Backend:** Python 3, Flask, psycopg2
- **СУБД:** PostgreSQL, pgAdmin 4
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5

# Информационная система по ремонту компьютерной техники «ТехСервис»

**Статус:** В разработке

**Учебная группа:** \[К-ИСП-232\]

**Учебный год:** 2026–2027

## 1. Описание проекта

«ТехСервис» — это веб-приложение, предназначенное для автоматизации работы сервисного центра по ремонту компьютерной техники. Система позволяет клиентам оформлять заявки на диагностику и ремонт, менеджерам — распределять задачи, а инженерам (мастерам) — обновлять статусы работы и выставлять стоимость. Проект реализует строгую ролевую модель для обеспечения безопасности и удобства использования.

## 2. Функциональные возможности

**Реализованные функции**

* Регистрация и авторизация пользователей.

* Ролевая модель доступа: Клиент, Менеджер, Мастер, Администратор.

* Раздельные личные кабинеты (дашборды) для каждой роли.

* Создание заявок на диагностику и ремонт (с указанием характеристик и проблемы).

* Назначение мастеров на конкретные заявки (интерфейс менеджера).

* Обновление статусов заявок и добавление отчетов/цены (интерфейс мастера).

* Отслеживание статуса ремонта в реальном времени (интерфейс клиента).

**Планируемые функции**

* Поиск и фильтрация заявок по дате и статусу.

* Интеграция SMS/Email уведомлений о готовности техники.

* Онлайн-оплата услуг ремонта.

* Отчетность и аналитика для администратора.

## 5. База данных

**СУБД:** PostgreSQL

В базе данных используются следующие основные сущности:

* **Пользователи (users):** Данные для авторизации и роли.

* **Клиенты (clients):** Контактная информация заказчиков.

* **Мастера (masters):** Специализация и данные инженеров.

* **Заказы (repair_orders):** Информация о технике, проблеме, мастере и статусе.

* **Услуги (services):** Прайс-лист типовых работ.

**Документация:**

* Скрипт создания таблиц и тестовых данных находится в файле `schema.sql`.

## 7. Установка и запуск

**Требования**

* Python 3.10+

* PostgreSQL 16+

**Установка**

1. Клонировать репозиторий:

   ```
   git clone https://github.com/RoyalMurder/pc-repair-system.git
   
   ```

2. Перейти в папку проекта:

   ```
   cd [pc_repair_system_v5]
   
   ```

3. Создать и активировать виртуальное окружение:

   ```
   python -m venv venv
   # Для Windows:
   .\venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
   
   ```

4. Установить необходимые зависимости:

   ```
   pip install Flask==3.0.2 Werkzeug==3.0.1 psycopg2-binary==2.9.10 --only-binary=:all:
   
   ```

5. Настроить базу данных:

   * Создать БД `pc_repair_db` в PostgreSQL.

   * Выполнить скрипт из файла `schema.sql` для создания структуры и тестовых пользователей.

6. Запустить приложение:

   ```
   python app.py
   
   ```

7. Открыть в браузере: `http://127.0.0.1:5000`
